# 実装上の判断

原本 requirements.md は変更せず、次の読み替えを記録します。

1. 企画メモは、明示的な例外条件「1字以下はエラー」を優先し、空白を除く2〜500 Unicodeコードポイントを許可します。
2. 目標尺はショートの記述を活かすため1〜1800秒を許可します。60秒未満は3ブロックへ縮約します。整数配分合計は必ず入力尺と一致します。
3. マスタの内訳を合計すると107件です（6+3+8+18+8+24+16+6+6+12）。記載された「117」に合わせて未指定10件を捏造せず、全10カテゴリの指定件数を実装しました。
4. 最短日程は企画確定を今日から可能として、後続工程に必要な9営業日を確保します。祝日は除外しません。固定撮影が準備可能日より前の場合、撮影固定の制約内で解消できないことと最短撮影日を明示します。
5. 月次比較の登録者増減は、仕様の数値制約を優先し非負整数です。維持率は0〜100の有限小数を許可します。率が数値表現範囲を超えた場合は算出不可の理由を表示します。
6. 企画内容変更時は依存する台本・編集指示書、台本/メモ/日程変更時は編集指示書を無効化します。古い内容を現行成果物として表示しません。日程の再計算でも各工程の完了状態は保持します。
7. APIはセッション所有者をレスポンスから除外します。CookieのHttpOnlyの意図を損なわないためです。
8. 自動分類は実装済みアダプタへ閉じ込め、未接続/障害時は手動選択に限定します。ライブ接続、無料枠適用、リクエスト段階の厳密version pinは公開前の確認事項です（ENV/PRODUCTION.md）。
